# Slot Booking System

> ⚠️ **Note:** This project is currently under development. The core logic is in place, but this is not the final product.

## Overview

This project is a work-in-progress application designed with scalability and flexibility in mind. While the current version implements the foundational logic and structure, further enhancements and new features are expected in future iterations.

## Key Points

- **Database Transition:**  
  The project currently utilizes Firebase (NoSQL). However, there are plans to refactor and migrate the backend to a relational SQL-based environment. Please consider this when reviewing or contributing to the codebase.

- **Core Logic Implemented:**  
  Most of the core functionality and logic flows have been implemented. This provides a working prototype that can be tested and further refined.

- **Future Enhancements:**  
  Additional functionality is expected to be added. As such, the current codebase should be view.
